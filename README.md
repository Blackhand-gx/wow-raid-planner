# 魔兽世界 团队副本规划器

基于 React + Konva 画布的团队副本战术布阵工具。支持副本地图叠加、团员拖拽部署、首领标记、战术标注（箭头/直线/圆形/文字），适用于开荒阶段的战术制定与复盘。

## 环境要求

- **Node.js** ≥ 18（推荐 20+）
- 包管理器：npm（项目自带 `package-lock.json`）

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器，默认运行在 http://localhost:5173
npm run dev

# 生产构建，输出到 dist/
npm run build
```

## 功能

- **战术画布** — Konva 无限画布，支持平移、缩放、框选批量操作
- **副本地图** — 上传自定义地图作为背景，支持透明度调节和独立缩放
- **团员管理** — 拖拽放置团员标记，支持职业、职责（坦克/治疗/输出）、团队标记
- **首领标记** — 预设 9 个首领（虚影尖塔 / 梦境裂隙 / 进军奎尔丹纳斯），一键切换
- **战术绘图** — 箭头、直线、圆形、文字标注，分层管理
- **截图导入** — 上传团队截图，半透明叠加辅助手动部署；支持 OCR 自动识别姓名和职业
- **撤销/重做** — 最多 50 步历史，自动保存至本地
- **导出** — 一键导出 PNG 图片或 JSON 存档文件

## 使用说明

### 基础流程

1. **选择副本预设** — 侧栏「首领」面板，下拉菜单选择版本 → 副本 → 首领，系统自动加载对应地图和首领图标
2. **部署团员** — 工具栏切到「选择」模式，侧栏「团员」面板点击「添加」，在画布上拖拽放置
3. **绘制战术** — 工具栏选择箭头/直线/圆形/文字工具，在画布上标注走位、分担、分散等
4. **导出** — 完成后导出 PNG 分享给团队，或导出 JSON 存档下次继续

### 团员导入（两种方式）

**手动导入：** 上传团队阵容截图 → 调整叠加位置和透明度 → 手动点击截图对应位置逐个添加团员

**OCR 自动识别：** 上传截图 → 系统自动扫描中英文姓名和职业色 → 在弹窗中校对结果 → 勾选后批量导入。底层使用 tesseract.js，首次使用需下载中文语言包（约 10 MB，仅一次）

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + S` | 导出 JSON 存档 |
| `Ctrl + O` | 打开 JSON 存档 |
| `Delete` / `Backspace` | 删除选中对象 |
| `Esc` | 取消选中 |
| 鼠标滚轮 | 缩放画布 |
| 鼠标拖拽空白区域 | 平移画布 |
| 双击团员 | 编辑详细信息 |

### 自动保存

编辑状态每 2 秒自动保存至浏览器 localStorage，关闭或刷新页面后数据不丢失。

## 目录结构

```
src/
├── components/          # React 组件
│   ├── canvas/          # 画布层级（背景/团员/首领/标注）
│   ├── dialogs/         # 弹窗（编辑/自动识别）
│   ├── layout/          # 布局（工具栏/侧栏/状态栏）
│   ├── nodes/           # 画布节点（团员/首领图标）
│   ├── panels/          # 侧栏面板
│   └── shared/          # 共享组件
├── data/                # 静态数据（职业/首领预设）
├── hooks/               # 自定义 Hook
├── store/               # Zustand 状态（按功能域切片）
├── types/               # TypeScript 类型定义
├── utils/               # 工具函数（序列化/导出/OCR）
└── styles/              # 全局样式
```
